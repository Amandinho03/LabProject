Rules this refactor enforces

  • One Tailwind config file, /js/tailwind-config.js, loaded by every page — colors and fonts can no longer drift between pages.
  • Montserrat everywhere; the old per-page mix of Montserrat, Inter and Newsreader is gone.
  • base-soft and border use the greener values from manage.html site-wide, since they read as more "on brand" than the old neutral grays.
  • Asset paths are always root-relative (/assets/...), matching how the server actually serves them.
  • The login/register hero image-and-quote logic lives once, in /js/auth-hero.js.
